# **App Name**: Salihli Explorer

## Core Features:

- POI Listing and Map: Display Salihli's points of interest (historical, natural, tourist) on a map and in a list.
- Detailed Location Pages with Text-to-Speech: Provide detailed information about each location, including a text-to-speech feature for auditory learning. QR codes link directly to the location page, automatically starting the audio.
- Thematic Route Display: Showcase curated routes with descriptions and lists of stops. Includes a 'Start Route' button to open the route in Google Maps, guiding users from their current location.
- Salihli Stories: Share local legends and cultural stories, allowing users to read or listen to the tales.
- Local Cuisine Discovery: Introduce local dishes with images and redirect users to a Google Maps search for nearby restaurants that serve them.
- Nearby Recommendations: Using user location, identify and list nearby points of interest, ranked by distance.
- Automatic Audio Guide Tool: Continuously monitor the user's location; provide toast notification with audio cue as the user approaches points of interest; redirect user to the page for detailed description. The LLM uses reasoning to decide when or if to incorporate some piece of information in its output, then use the word 'tool' in the description of the feature

## Style Guidelines:

- Primary color: Emerald Green (#28914B) to reflect the fertile lands of Salihli.
- Background color: Light beige (#F5F5DC), complementing the emerald green, while remaining desaturated and bright.
- Accent color: Golden Yellow (#FFD700) as a contrast, referencing the historical richness.
- Body font: 'PT Sans', sans-serif, for both headlines and body, lending a balance of modernity and approachability to all text content.
- Use minimalist icons in gold to represent categories and actions.
- Implement a dynamic layout, focusing on a full-screen hero video and card-based presentation of destinations.
- Use subtle transition animations to enhance user experience, such as cross-fades and fly-in effects.
